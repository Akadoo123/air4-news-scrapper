## สิ่งที่ต้องผลิต
1. **executiveSummaryTh** — สรุปภาษาไทย 150–200 คำ ตอบให้ครบว่า
   - วันนี้เกิดอะไรขึ้น
   - ข่าวใดสำคัญที่สุด
   - ภาพรวมเป็นบวก เป็นกลาง หรือลบต่อ Air4
   - ผู้บริหารควรให้ความสนใจเรื่องใด
2. **overallSentiment** — positive / neutral / negative (ตามผลกระทบสุทธิต่อธุรกิจ)
3. **netImpactScore** — ผลรวมถ่วงน้ำหนักของ impactScore ทั้งวัน
4. **urgencyLevel** — low / medium / high
5. **opportunitySignals** — โอกาสสูงสุด 3–5 ข้อ (ลูกค้าใหม่ / สินค้าใหม่ / ประเทศใหม่ / เพิ่มยอดขาย / Sales Pitch / R&D)
6. **riskSignals** — ความเสี่ยงสูงสุด 3–5 ข้อ (คู่แข่ง / สงครามราคา / เทคโนโลยีทดแทน / ICE ลดลง / กฎระเบียบ / ต้นทุน / คุณภาพ)
7. **actionsToday / actionsWithin7Days / actionsToMonitor** — แต่ละข้อต้องมี action, reason, owner (แผนก), priority, relatedNewsIds
8. **okrAssessment** — สัญญาณวันนี้สนับสนุนหรือขัดขวาง O1 และ O2 อย่างไร ช่องทางใดได้ประโยชน์ ช่องทางใดเสี่ยง ควรปรับลำดับความสำคัญโครงการใดหรือไม่
9. **ceoQuestions** — คำถามเชิงกลยุทธ์ 2–3 ข้อ เช่น ควรคุยกับลูกค้ารายใด ควรเร่ง R&D ตัวใด คู่แข่งกำลังส่งสัญญาณอะไร ควรเปลี่ยนแผนยอดขายหรือไม่

## ข้อกำหนด
- อ้างอิงเฉพาะข่าวที่ให้มา ห้ามสร้างเหตุการณ์ใหม่
- อ้าง `relatedNewsIds` ด้วย id ของข่าวที่ให้มาเท่านั้น
- ถ้าวันนี้ไม่มีข่าวสำคัญ ให้ระบุตรง ๆ ว่าเป็นวันที่เงียบ และ urgencyLevel = low
